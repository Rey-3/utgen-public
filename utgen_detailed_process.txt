UTGEN DETAILED CLASS AND FUNCTION EXPLANATION
==============================================

This file explains the current source code in the utgen package.

Notation:

  Input
    Values received by a function.

  Operation
    What the function does.

  Return
    What the function gives back.

  Cursor
    A node from Clang's syntax tree.

  TranslationUnit
    The complete parsed C source file.


0. COMPLETE CALL ORDER
----------------------

Normal entry point:

  generate_from_config.py
    __main__
      mp.freeze_support()
      run()
        projects_from_config()
        ModuleIndexer.index()
        XmlDbWriter.write()
        run_function()
          generate_function()
            RowAssembler.assemble()
            Verifier.check()
            ValueXmlWriter.write()
            StubXmlWriter.write()
            ReportWriter.write()

Per-function indexing order:

  ModuleIndexer._function()
    InventoryBuilder.build()
    AtomBuilder(...)
    DecisionExtractor.extract()
    BodyIrBuilder.build()
    DataflowEngine.analyze()


1. ModuleIndexer
----------------

File: utgen/db.py

ModuleIndexer is the main source-analysis coordinator. It receives one C
source file and produces one ModuleAnalysis object.


1.1 ModuleIndexer.__init__(self, config=None)

Input:

  config
    Usually a dictionary. It may also be an object containing configuration
    attributes.

Example:

  ModuleIndexer({
      "defines": ("__GHS__",),
      "includes": ["C:\\MinGW\\include"],
  })

Operation:

  Save config in self.config.

Return:

  None.

The constructor does not parse C and does not build an inventory. It only
stores configuration for later index() calls.


1.2 ModuleIndexer._get(self, name, default=None)

Input:

  name
    Configuration key or attribute name.

  default
    Value used when the setting does not exist.

Operation:

  If self.config is dictionary-like:

    self.config.get(name, default)

  Otherwise:

    getattr(self.config, name, default)

Example with a dictionary:

  config = {"defines": ("DEBUG",)}

  _get("defines", ())
    returns ("DEBUG",)

  _get("includes", ())
    returns ()

Example with an object:

  config.defines = ("DEBUG",)

  _get("defines", ())
    returns ("DEBUG",)

Return:

  The configuration value or default.


1.3 ModuleIndexer.index(self, source, root_path=None)

Input:

  source
    Path to the target .c file.

  root_path
    Root directory used by IncludeScanner. If omitted, source.parent is used.

Operation:

  1. Convert source and root_path to pathlib.Path objects.
  2. Call self._includes(source, root_path).
  3. Call configure_libclang().
  4. Call ClangParser().parse().
  5. Collect macros with self._macros().
  6. Create InventoryBuilder.
  7. Register global types with self._register_globals().
  8. Find function definitions with function_definitions().
  9. For each function cursor, call self._function().
  10. Create ModuleAnalysis containing:
        source path
        source sha256
        include directories
        headers and header hashes
        macros
        enums
        structs
        globals
        FunctionIR objects
  11. Call _set_constants().
  12. Call _set_local_functions().
  13. Return the ModuleAnalysis.

Return:

  ModuleAnalysis

Example:

  analysis = ModuleIndexer(config).index(
      Path("tests/c_samples/basic.c")
  )

  analysis.functions
    contains FunctionIR for testfunc.

This is the main function that starts source analysis.


1.4 ModuleIndexer._includes(self, source, root_path)

Input:

  source
    Target source file.

  root_path
    Include search root.

Operation:

  1. Create IncludeScanner.
  2. Start with configured include directories.
  3. Add directories found by IncludeScanner.
  4. Remove duplicate directories.
  5. Create header records:
        (header_name, resolved_path, sha256)

Return:

  (include_dirs, headers)

Example:

  (
      ["C:\\MinGW\\include", "D:\\Project\\include"],
      [("types.h", "D:\\Project\\include\\types.h", "...")]
  )


1.5 ModuleIndexer._register_globals(self, tu, builder)

Input:

  tu
    Parsed TranslationUnit.

  builder
    InventoryBuilder containing a TypeGraph.

Operation:

  1. Walk every Clang cursor using _walk().
  2. For every ENUM_DECL, register the enum in builder.type_graph.
  3. For every file-scope VAR_DECL, describe its type.

Example source:

  typedef enum {
      OFF = 0,
      ON = 1
  } State;

  State current_state;

The enum and the global variable type are registered before functions are
processed.

Return:

  None.

Important:

  This function prepares the type graph. It does not yet create the per-
  function Inventory.


1.6 ModuleIndexer._globals(self, tu, builder)

Input:

  tu
    Parsed TranslationUnit.

  builder
    InventoryBuilder with a populated TypeGraph.

Operation:

  1. Walk all cursors.
  2. Keep only file-scope variable declarations.
  3. Avoid duplicate name/file pairs.
  4. Describe each type.
  5. Create GlobalDef records containing:
        name
        type
        dimensions
        extern flag
        static flag
        const flag
        volatile flag
        source file

Return:

  List of GlobalDef objects.


1.7 ModuleIndexer._macros(self, tu)

Input:

  tu
    Parsed TranslationUnit.

Operation:

  1. Walk all cursors.
  2. Keep MACRO_DEFINITION cursors.
  3. Ignore compiler-system macros beginning with __.
  4. Parse each source #define using _macro().
  5. Fold object-like macro values repeatedly.
  6. Create MacroDef objects.

Example:

  #define LIMIT 10
  #define LIMIT_PLUS_ONE (LIMIT + 1)

Possible result:

  MacroDef("LIMIT", "object", "10", 10, ...)
  MacroDef("LIMIT_PLUS_ONE", "object", "(LIMIT + 1)", 11, ...)

Return:

  List of MacroDef objects.


1.8 ModuleIndexer._function(self, cursor, tu, inventory_builder, macros=None)

Input:

  cursor
    Clang function-definition cursor.

  tu
    TranslationUnit.

  inventory_builder
    Shared InventoryBuilder and TypeGraph.

  macros
    Module macro records.

Operation:

  1. Call inventory_builder.build(cursor, tu).
  2. Create AtomBuilder using the resulting Inventory.
  3. Call DecisionExtractor(atom_builder).extract(cursor).
  4. Call BodyIrBuilder(atom_builder, decisions, macros).build(cursor).
  5. Read parameter type/name pairs.
  6. Create FunctionIR.
  7. Call DataflowEngine().analyze(function).
  8. Return the completed FunctionIR.

Return:

  FunctionIR

The important order is inventory first, decisions second, body IR third, and
dataflow last.


1.9 ModuleIndexer._get configuration examples

The normal batch creates:

  ModuleIndexer({
      "defines": ("__GHS__",),
      "includes": include_dirs,
  })

Therefore:

  _get("defines", ())
    returns ("__GHS__",)

  _get("includes", ())
    returns include_dirs

  _get("char_signed", False)
    returns False because the key is absent

  _get("const_globals", "inject")
    returns "inject" because the key is absent

  _get("no_stub", DEFAULT_NO_STUB)
    returns DEFAULT_NO_STUB because the key is absent


2. IncludeScanner
-----------------

File: utgen/includes.py

IncludeScanner finds headers reachable from a source file.


2.1 IncludeScanner.__init__(self, source_file, root_path, debug=False)

Input:

  source_file
    Target source path.

  root_path
    Directory under which headers are searched.

  debug
    Whether permission-skip messages are printed.

Operation:

  Initialize include_full_paths, resolved, and missing dictionaries/lists.
  Immediately scan the includes of source_file.

Return:

  None.


2.2 IncludeScanner.get_unique_include_dirs(self)

Input:

  No arguments.

Operation:

  Convert resolved header paths into unique include-root directories. Relative
  include pieces and self-named subdirectories are stripped.

Return:

  List of directory strings.


2.3 IncludeScanner._walk(self, filenames)

Input:

  filenames
    Include filenames waiting to be resolved.

Operation:

  For each filename:

  1. Skip it if already in resolved.
  2. Search for it with _find_file().
  3. Save the path or None.
  4. If found, scan its includes recursively.
  5. If not found, add it to missing and print an error.

Return:

  None.


2.4 IncludeScanner._includes_of(self, source_file)

Input:

  source_file
    File to read.

Operation:

  1. Detect its encoding.
  2. Read lines while ignoring decode errors.
  3. Match #include <x.h> and #include "x.h".
  4. Return base filenames.

Return:

  List of include names.


2.5 IncludeScanner._encoding_of(self, source_file)

Input:

  Source path.

Operation:

  Use chardet when installed to detect encoding.

Return:

  Encoding string or None.


2.6 IncludeScanner._find_file(self, root_dir, target)

Input:

  root_dir
    Directory to search.

  target
    Header filename.

Operation:

  Recursively scan files and directories. Compare names case-insensitively.

Return:

  Matching path string or None.


3. clang_setup.py
-----------------

3.1 configure_libclang(path=None)

Input:

  path
    Optional DLL file or directory.

Operation:

  1. Return immediately when already configured.
  2. Check bundled locations.
  3. Check explicit path.
  4. Check LIBCLANG_PATH.
  5. Use the default LLVM location.
  6. Add libclang.dll when path is a directory.
  7. Raise FileNotFoundError when missing.
  8. Configure clang.cindex.Config.

Return:

  None.


4. parsing.py
--------------

4.1 ParseError

Exception type for fatal Clang diagnostics.


4.2 ClangParser.__init__

No explicit constructor is defined. Python creates the default object.


4.3 ClangParser.parse(self, source, includes, defines=())

Input:

  source
    C source Path.

  includes
    Include directories.

  defines
    Defines with or without the -D prefix.

Operation:

  1. Configure libclang.
  2. Start args with -x c.
  3. Add -I arguments.
  4. Add -D arguments.
  5. Call Index.create().parse().
  6. Request detailed preprocessing records.
  7. Collect fatal diagnostics.
  8. Raise ParseError if any fatal diagnostic exists.

Return:

  TranslationUnit.


4.4 function_definitions(tu)

Input:

  tu
    Parsed TranslationUnit.

Operation:

  1. Normalize tu.spelling to get the main source path.
  2. Visit top-level cursors.
  3. Skip cursors that are not FUNCTION_DECL.
  4. Skip declarations where is_definition() is False.
  5. Skip definitions located in included headers.
  6. Store remaining cursors by cursor.spelling.

Return:

  Dictionary from function name to Clang cursor.

Example:

  {
      "testfunc": <Cursor>,
      "static_helper": <Cursor>,
  }


5. typegraph.py
---------------

5.1 clean_name(spelling)

Input:

  A Clang type spelling.

Operation:

  Remove const, volatile, struct, union, and enum words.

Example:

  clean_name("const struct Config")
    returns "Config"

Return:

  Clean type name string.


5.2 dims_suffix(dims)

Input:

  Tuple of array dimensions.

Example:

  dims_suffix((4, 5))
    returns "[4][5]"

Return:

  Dimension suffix string.


5.3 TypeGraph.__init__(self, char_signed=False)

Input:

  char_signed
    Whether plain char is signed.

Operation:

  Create empty structs and enums dictionaries and internal type identity maps.

Return:

  None.

Why char_signed exists:

  Plain char can be signed or unsigned depending on compiler/target.

  signed char range:
    -128..127

  unsigned char range:
    0..255


5.4 TypeGraph.describe(self, ctype, name, bitfield_width=None)

Input:

  ctype
    Clang type object.

  name
    Variable or member name.

  bitfield_width
    Optional declared bitfield width.

Operation:

  1. Remove array layers and collect dimensions.
  2. Get the canonical type.
  3. Record const information.
  4. Handle bitfields first.
  5. Classify pointers.
  6. Classify records.
  7. Classify enums.
  8. Classify integer types.
  9. Mark unsupported types.

Return:

  MemberDef.

Examples:

  uint8 x
    -> MemberDef("x", "uint8", "scalar", 8, (), False, False, False)

  Config cfg
    -> MemberDef("cfg", "Config", "struct", 0, (), ...)

  uint8 values[4]
    -> MemberDef("values", "uint8", "scalar", 8, (4,), ...)

  uint8 enabled : 1
    -> scalar MemberDef with len_bits=1 and bitfield=True.

This function describes a type. It does not yet create a final Variable leaf.


5.5 TypeGraph.register(self, ctype)

Input:

  Clang record or enum type.

Operation:

  Call _register_record() for a struct/union or _register_enum() for an enum.

Return:

  Clean registered type name.


5.6 TypeGraph._register_record(self, ctype, canon)

Operation:

  1. Get the declaration and USR.
  2. Reuse an existing registered name when seen.
  3. Insert an empty placeholder.
  4. Describe every field.
  5. Replace the placeholder with the complete StructDef.

Return:

  Struct or union type name.

The placeholder prevents infinite recursion for self-referencing structs.


5.7 TypeGraph._register_enum(self, ctype, canon)

Operation:

  Read every ENUM_CONSTANT_DECL child and store its name/value pair.

Return:

  Enum type name.


5.8 TypeGraph._name_for(self, ctype, canon)

Return:

  The declared type name, or a generated name such as <anon1> for anonymous
  types.


5.9 TypeGraph._is_signed(self, canon)

Return:

  True for signed integer types.
  char_signed for plain char.
  False for unsigned types.


5.10 _file_of(decl)

Input:

  Clang declaration cursor.

Return:

  Source path string or empty string.


5.11 LeafDeriver.__init__(self, graph)

Input:

  graph
    TypeGraph containing StructDef and EnumDef records.

Operation:

  Store the graph.


5.12 LeafDeriver.leaves(self, member, direction)

Input:

  member
    Root MemberDef.

  direction
    IN, OUT, or INOUT.

Operation:

  Start recursive _emit() with an empty path.

Return:

  List of Variable objects.


8. atoms.py
-----------

8.1 _Value

_Value is an internal container used while AtomBuilder resolves an expression.

It can hold:

  variable
    A controllable Variable.

  constant
    A folded integer.

  node
    A nested Atom/And/Or/Not node.

It is not normally returned to the caller. It is used between AtomBuilder
helper functions.


8.2 CopyPropagation.__init__(self)

Operation:

  Create empty maps for:

    _bindings
      Local declaration -> source expression.

    _member_bindings
      Local member path -> source expression.

    _locals
      Known local declaration identities.

    _loop_written
      Values written inside loops.

Return:

  None.


8.3 CopyPropagation.record(self, stmt_cursor)

Input:

  stmt_cursor
    Function, block, declaration, assignment, or loop cursor.

Operation:

  1. If it is a function/block, recursively record children.
  2. For declarations, record the initializer.
  3. For assignments, bind the left side to the right side.
  4. For compound assignments, mark the result as not directly copyable.
  5. For loops, mark variables written by the loop as unknown afterwards.

Example:

  uint8 copied = input;

The binding becomes:

  copied -> input

Return:

  None. Internal binding maps are modified.


8.4 CopyPropagation.resolve(self, expr_cursor)

Input:

  Expression cursor.

Operation:

  Call resolve_expr(). If the result is a Cursor, convert it into a source path.

Return:

  Source path string or None.

Example:

  copied
    returns "input" when copied was assigned from input.


8.5 CopyPropagation.resolve_expr(self, expr_cursor, seen=None)

Input:

  Expression cursor.

Operation:

  1. Remove wrappers.
  2. Convert the expression into a raw path.
  3. Stop when the path was written in a loop.
  4. Follow member bindings.
  5. Follow declaration bindings.
  6. Resolve address/dereference wrappers.
  7. Resolve member and array paths.
  8. Return the original cursor when no binding exists.
  9. Stop when a cycle is detected.

Return:

  Cursor, source path, constant-like value, or None.


8.6 CopyPropagation._follow(self, value, seen)

Input:

  value
    A binding value.

  seen
    Keys already followed.

Operation:

  Follow bindings until reaching a source cursor or a cycle.

Return:

  Final source value.


8.7 CopyPropagation.snapshot(self)

Return:

  Copies of all binding, local, and loop-written state.

This is used before entering a branch.


8.8 CopyPropagation.restore(self, state)

Input:

  state
    Snapshot returned by snapshot().

Operation:

  Replace current binding state with the snapshot.

Return:

  None.


8.9 CopyPropagation.merge(self, *states)

Input:

  Branch snapshots.

Operation:

  Keep only bindings identical in every state. Union local declarations and
  loop-written names conservatively.

Example:

  branch 1: x -> 5
  branch 2: x -> 5

Result:

  x -> 5

Example:

  branch 1: x -> 5
  branch 2: x -> 10

Result:

  x cannot be safely copy-propagated.

Return:

  Merged snapshot.


8.10 CopyPropagation._set(self, lhs, rhs)

Input:

  lhs
    Assignment target cursor.

  rhs
    Source cursor or None.

Operation:

  Store declaration and local-member bindings unless the target is static.

Return:

  None.


8.11 CopyPropagation._is_local(self, cursor)

Return:

  True when the root declaration belongs to a known local.


8.12 CopyPropagation._mark_loop_writes(self, cursor)

Operation:

  Recursively find assignment targets inside a loop and add their declaration
  keys and paths to _loop_written.

Return:

  None.


8.13 AtomBuilder.__init__(self, inventory, copyprop=None, macros=None)

Input:

  inventory
    Variables that may be controlled.

  copyprop
    Optional CopyPropagation object.

  macros
    Optional MacroDef list.

Operation:

  Store inventory and copy propagation. Convert macros into a lookup map.
  Create constants and uncontrollable lists.

Return:

  None.


8.14 AtomBuilder.build(self, cond_cursor)

Input:

  cond_cursor
    Clang condition expression.

Operation:

  Call _node(cond_cursor).

Return:

  Atom, And, Or, or Not.

Example:

  x > 10 && enabled

Return shape:

  And((
      Atom(x, GT, 10),
      Atom(enabled, TRUTHY),
  ))


8.15 AtomBuilder.build_case(self, subject_cursor, label_cursor)

Input:

  subject_cursor
    Switch expression.

  label_cursor
    Case label.

Operation:

  Resolve subject and label. When the subject is controllable, create an EQ
  atom. Otherwise record an uncontrollable condition.

Return:

  Atom(subject_variable, EQ, label_value) or an uncontrollable Atom.


8.16 AtomBuilder._node(self, cursor)

Operation:

  1. Remove wrappers.
  2. Convert && to And.
  3. Convert || to Or.
  4. Convert relational operators with _relation().
  5. Convert & mask expressions to BITSET.
  6. Convert ! to Not.
  7. Convert variables to TRUTHY.
  8. Convert constants to degenerate/uncontrollable atoms.
  9. Use _unknown() for unsupported expressions.

Return:

  Boolean model node.


8.17 AtomBuilder._relation(self, cursor, left_cursor, right_cursor, op)

Input:

  cursor
    Complete comparison cursor.

  left_cursor, right_cursor
    Comparison operands.

  op
    Op such as GT or EQ.

Operation:

  Resolve both operands. Create variable-vs-constant or variable-vs-variable
  atoms. Try bit-test and linear-expression handling when direct mapping fails.

Return:

  Atom or uncontrollable Atom.


8.18 AtomBuilder._bit_relation(self, cursor, left, right, op)

Operation:

  Convert these forms:

  (flags & 2) == 2
  (flags & 2) != 0

into BITSET atoms or their Not form.

Return:

  Atom, Not(Atom), or None.


8.19 AtomBuilder._value(self, cursor)

Input:

  Operand cursor.

Operation:

  1. Ask CopyPropagation to resolve it.
  2. Look for folded integer constants.
  3. Look for macro constants.
  4. Look up source paths in Inventory.
  5. Recognize nested binary nodes.
  6. Recognize stub return paths such as tessy_get_value.

Return:

  _Value.


8.20 AtomBuilder._linear(self, cursor)

Recognizes simple expressions:

  x + 3
  x - 3
  3 + x

Return:

  (Variable, offset) or None.


8.21 AtomBuilder._find_variable(self, path, address=False)

Input:

  path
    Source path.

  address
    Whether to check address_of mappings.

Operation:

  Try exact names, array-normalized names, and static-local suffixes.

Return:

  Variable or None.


8.22 AtomBuilder._unknown(self, cursor)

Input:

  Unsupported condition cursor.

Operation:

  Record source text in uncontrollable and create an Atom without a Variable.

Return:

  Atom(None, Op.TRUTHY, text=source_text).


8.23 atoms.py helper functions

  _unwrap(cursor)
    Remove Clang wrapper expressions while preserving meaningful children.

  _last_non_type_child(cursor)
    Find the last child that is not a type reference.

  _root(cursor)
    Walk member/index expressions to their root declaration.

  _is_static(cursor)
    Check the root declaration storage class.

  _common_bindings(*mappings)
    Keep binding entries identical in every mapping.

  _cursor_key(cursor)
    Return a Clang USR for a declaration/reference.

  _raw_path(cursor)
    Convert declaration, member, array, pointer, and call cursors into paths.

  _callee_name(cursor)
    Return the referenced function spelling.

  _constant(cursor)
    Fold enum values, unary values, arithmetic, and literals.

  _macro_constant(cursor, macros=None)
    Resolve a macro at a source location.

  _fold_int(raw, macros=None, seen=())
    Fold a small C integer expression used by macros.

  _fold_node(node, macros, seen)

  _operator(cursor)
    Read an operator from cursor spelling or tokens.

  _compare(left, right, op)
    Apply an Op comparison to two integers.

  _source(cursor)
    Return normalized source token text.


9. decisions.py
----------------

9.1 _SourceAtomBuilder.__init__

No explicit constructor is defined. The default object is empty.


9.2 _SourceAtomBuilder.build(self, cursor)

Input:

  Condition cursor.

Operation:

  Convert the entire source text into an uncontrollable truthy Atom.

Return:

  Atom(None, Op.TRUTHY, text=source_text).

This is a fallback when a real AtomBuilder is not supplied.


9.3 _Arm

Internal switch arm record:

  labels
    Case label cursors.

  body
    Statements in the arm.

  default
    Whether this is the default arm.


9.4 DecisionExtractor.__init__(self, atom_builder=None)

Input:

  atom_builder
    Optional real AtomBuilder.

Operation:

  Save the real builder or create _SourceAtomBuilder(). Initialize:

  _decisions = []
  _guards = []
  _next_id = 1

Return:

  None.


9.5 DecisionExtractor.extract(self, body_cursor)

Input:

  body_cursor
    Function cursor or compound body cursor.

Operation:

  1. Clear previous decisions and guards.
  2. Reset next decision ID to 1.
  3. If given a function, find its compound body.
  4. Walk the body with _statement().
  5. Return the decisions collected by _record().

Return:

  List of Decision objects.

Important:

  It does not return the body. The body is only scanned. The return value is
  self._decisions.


9.6 DecisionExtractor._function_body(self, cursor)

Input:

  Function cursor.

Operation:

  Look through children for a COMPOUND_STMT.

Return:

  Compound body Cursor or None.


9.7 DecisionExtractor._statement(self, cursor)

Input:

  One Clang statement cursor.

Operation:

  Dispatch based on cursor.kind:

  COMPOUND_STMT
    Call _block().

  IF_STMT
    Call _if().

  SWITCH_STMT
    Call _switch().

  WHILE_STMT/FOR_STMT
    Call _loop().

  DO_STMT
    Call _do_loop().

  Declaration/assignment
    Record copy propagation and scan nested expressions.

  Return/call/unary/null
    Scan nested expressions.

  Other nodes
    Recursively inspect children.

Return:

  None. Decisions are stored in self._decisions.


9.8 DecisionExtractor._block(self, cursor)

Operation:

  Process child statements in source order. Stop after a statement that
  _ends_in_return() returns True.

Return:

  None.


9.9 DecisionExtractor._if(self, cursor)

Input:

  IF_STMT cursor.

Operation:

  1. Read condition, then cursor, and else cursor.
  2. Create and append a Decision.
  3. Find nested expressions in the condition.
  4. Save current guard depth and copy-propagation state.
  5. Process the then branch under Guard(decision.expr, True).
  6. Restore the state from before the if.
  7. Check whether the then branch returns.
  8. Process the else branch under Guard(decision.expr, False).
  9. Check whether the else branch returns.
  10. Merge then and else copy-propagation states.
  11. Remove temporary guards.
  12. If the then branch returns and the else path continues, append a false
      guard for code after the if.

Return:

  None.

Example:

  if (error) {
      return;
  }

  after_work();

The later code receives guard:

  error == FALSE


9.10 DecisionExtractor._switch(self, cursor)

Operation:

  1. Read switch subject and body.
  2. Group cases with _arms().
  3. Build case expressions.
  4. Record one Decision per arm.
  5. Process each arm under true guard.
  6. Merge arm states.
  7. Add false guards after returning arms.

Return:

  None.


9.11 DecisionExtractor._arms(self, body)

Input:

  Switch body cursor.

Return:

  List of _Arm objects.


9.12 DecisionExtractor._case_chain(self, cursor)

Input:

  First CASE_STMT in a possible chain.

Operation:

  Combine consecutive labels:

  case 1:
  case 2:
      work();

Return:

9.27 DecisionExtractor._guard(self, expr, outcome)

This is the FILO guard-stack function.

Operation when entering:

  self._guards.append(Guard(expr, outcome))

Operation when leaving:

  self._guards.pop()

Example:

  with self._guard(A, True):
      with self._guard(B, True):
          pass

Stack states:

  enter A -> [A]
  enter B -> [A, B]
  leave B -> [A]
  leave A -> []

Return:

  It is a context manager, not a normal value-returning function.

18. assembler.py
-----------------

18.1 RowAssembler.__init__(self, solver, mcdc, fault_overrides=None,
                           include_boundary=True, include_fault=True)

Input:

  solver
    Solver object.

  mcdc
    McdcGenerator object.

  include_boundary/include_fault
    Feature switches.

Operation:

  Store all generators and switches.

Return:

18.2 RowAssembler.assemble(self, function)

Input:

  FunctionIR.

Operation:

  1. Call _inputs().
  2. Call _defaults().
  3. If no decisions exist, return one Nominal row.
  4. Create CoverageGenerator.
  5. For every decision:
       a. Report uncontrollable atoms.
       b. Create guard alternatives.
       c. Create MC/DC assignments.
       d. Convert assignments into constraints.
       e. Call Solver.solve().
       f. Combine solved values with defaults.
       g. Create intent and description.
       h. Deduplicate identical rows.
       i. Add concrete Coverage rows.
  6. If include_boundary, add BoundaryGenerator rows.
  7. If include_fault, add FaultGenerator rows.

Return:

  (rows, notes)

Example:

  rows, notes = RowAssembler(
      Solver(),
      McdcGenerator(),
      include_boundary=False,
      include_fault=False,
  ).assemble(function)

24. BASIC END-TO-END EXAMPLE
----------------------------

Input:

  typedef unsigned char uint8;

  typedef struct {
      uint8 isvalid;
      uint8 code;
  } mystruct;

  extern mystruct get_lol_msg(void);

  uint8 testfunc(uint8 num, mystruct test) {
      mystruct lol = get_lol_msg();
      uint8 ret = 0;

      if (lol.isvalid && test.isvalid) {
          if (num > 10) {
              ret = 13;
          }
      }

      return ret;
  }

ModuleIndexer.index() creates:

  Function name:
    testfunc

  Stub:
    get_lol_msg returns mystruct

  Leaves:
    num
    test.isvalid
    test.code
    testfunc()
    tessy_get_lol_msg.isvalid
    tessy_get_lol_msg.code

  Decisions:
    Decision 1: tessy_get_lol_msg.isvalid && test.isvalid
    Decision 2: num > 10

  Guard:
    Decision 2 requires Decision 1 == TRUE

Normal batch rows:

  Row 1:
    num=0
    test.isvalid=1
    tessy_get_lol_msg.isvalid=1
    expected testfunc()=0

  Row 2:
    num=0
    test.isvalid=1
    tessy_get_lol_msg.isvalid=0
    expected testfunc()=0

  Row 3:
    num=0
    test.isvalid=0
    tessy_get_lol_msg.isvalid=1
    expected testfunc()=0

  Row 4:
    num=11
    test.isvalid=1
    tessy_get_lol_msg.isvalid=1
    expected testfunc()=13

Output files:

  db_<module>.xml
  value_<module>_testfunc.xml
  stub_<module>_testfunc.xml
  report_<module>_testfunc.md

Input:

  id() of a Boolean node.

Operation:

  Look up the original node in _ATOM_NODES and return all Atom descendants.

Return:

  Tuple of Atoms.


27.2 _atoms_of(node)

Input:

  Boolean expression node.

Operation:

  Store the node by object ID and call _cached_atoms().

Return:

  Tuple of Atoms.


27.3 _clear_atoms()

Operation:

  Clear the node map and cache.

Return:

  None.

It is attached as cache_clear support to _atoms_of().








5.13 LeafDeriver._emit(self, out, prefix, member, direction, fmt, pointer, visited)

Operation:

  1. Skip function pointers and unsupported types.
  2. Build the current dotted/array path.
  3. Mark pointer paths.
  4. Recursively explode structs/unions.
  5. Emit enum Variables with enum domains.
  6. Emit scalar Variables with CType bounds.
  7. Stop recursive type cycles.

Example:

  Config cfg containing uint8 value
    produces cfg.value.


5.14 LeafDeriver._join(self, prefix, name)

Return:

  prefix.name, name, or prefix when the member is anonymous.


6. inventory.py
----------------

6.1 InventoryBuilder.__init__(self, char_signed=False,
                              const_globals="inject",
                              no_stub=DEFAULT_NO_STUB)

Input:

  char_signed
    Plain char signedness.

  const_globals
    "inject" or "fold".

  no_stub
    Function names that should not become stubs.

Operation:

  Create TypeGraph, LeafDeriver, and StubFinder objects.

Return:

  None.


6.2 InventoryBuilder.build(self, func_cursor, tu)

Input:

  func_cursor
    Function definition.

  tu
    TranslationUnit.

Operation:

  1. Clear usage state.
  2. Scan function references.
  3. Add parameter address leaves.
  4. Describe and derive parameter leaves.
  5. Add return leaf when non-void.
  6. Add global leaves with calculated direction.
  7. Add static-local leaves.
  8. Find stubs and stub leaves.

Return:

  Inventory(variables, stubs).


6.3 InventoryBuilder._pointer_address(param)

Input:

  Pointer parameter cursor.

Return:

  Address Variable such as @p, or None for non-pointers/function pointers.


6.4 InventoryBuilder._statics(func_cursor)

Input:

  Function cursor.

Operation:

  Recursively find static VAR_DECL nodes and assign unique names.

Return:

  List of (declaration, static_name).


6.5 InventoryBuilder._globals(func_cursor)

Return:

  Global declarations used by the function and their directions.


6.6 InventoryBuilder._direction_of(entry)

Input:

  [declaration, read_flag, written_flag]

Return:

  IN when read only.
  OUT when written only.
  INOUT when both.


6.7 InventoryBuilder._scan(self, cur, writing)

Operation:

  Recursively inspect expressions. Assignment left sides are scanned with
  writing=True. Compound assignment left sides are scanned both as read and
  written. Address-of expressions are treated as read/write.

Return:

  None. It updates self._usage.


6.8 InventoryBuilder._record_ref(self, cur, writing)

Operation:

  Resolve cur.referenced. Keep function parameters and file-scope variables.
  Ignore local variables. Update read/write flags in self._usage.

Return:

  None.


6.9 InventoryBuilder._is_assign(self, cur)

Return:

  True when the cursor represents a normal = assignment.

It uses Clang's binary_operator API when available and token scanning as a
fallback.


6.10 InventoryBuilder._two_children(self, cur)

Return:

  Two children when exactly two exist, otherwise (None, None).


6.11 InventoryBuilder._first_token(self, cur)

Return:

  First token spelling or empty string.


6.12 inventory._is_static(cursor)

Return:

  True when the declaration storage class is static.


7. stubs.py
-----------

7.1 StubFinder.__init__(self, graph, deriver, no_stub=DEFAULT_NO_STUB)

Input:

  graph
    TypeGraph.

  deriver
    LeafDeriver.

  no_stub
    Iterable of excluded function names.

Operation:

  Store graph, deriver, and a set(no_stub).


7.2 StubFinder.find(self, func_cursor)

Input:

  Function definition cursor.

Operation:

  Start recursive call scanning with empty seen/stub/variable collections.

Return:

  (list_of_StubInfo, list_of_stub_Variables)


7.3 StubFinder._walk(self, cur, self_name, source_file, seen, stubs, variables)

Operation:

  If cur is CALL_EXPR, call _record(). Then recursively visit children.

Return:

  None.


7.4 StubFinder._record(self, cur, ...)

Operation:

  1. Determine callee name.
  2. Skip recursion, no-stub names, duplicates, and local definitions.
  3. Create StubInfo.
  4. Create tessy leaves when the call has a non-void return.

Return:

  None. Lists are mutated.


7.5 StubFinder._is_local_definition(self, callee, source_file)

Return:

  True when callee.get_definition() is in source_file.


7.6 StubFinder._file_of(self, cursor)

Return:

  Normalized cursor source path.


7.7 StubFinder._stub_info(self, name, callee)

Return:

  StubInfo containing name, return metadata, and parameter type/name pairs.


7.8 StubFinder._return_of(self, callee)

Return:

  (CType, None) for scalar/enum/pointer.
  (None, struct_name) for struct/union.
  (None, None) for void/unsupported.


7.9 StubFinder._stub_type_name(self, ctype)

Return:

  Readable parameter type spelling.


7.10 StubFinder._tessy_leaves(self, name, callee)

Operation:

  1. Return no leaves for void calls.
  2. Derive tessy_<name> return leaves.
  3. For each parameter, derive OUT capture leaves named
     tessy_<name>__ArgN.

Return:

  List of Variable objects.
